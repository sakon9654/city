# WORLD BUILDING 04.1 — แนวทางออกแบบผู้นำองค์กร
สถานะ: PROPOSAL (รอผู้เขียนรับรองรายตัวละคร)

## แนวคิดหลักที่ผู้เขียนกำหนด
หัวหน้าองค์กรใหญ่ไม่จำเป็นต้องมีพลังพิเศษด้านการต่อสู้ที่สูงสุด ความสามารถในการคุมคนจำนวนมากมาจากฝีมือการต่อสู้ การประเมินสถานการณ์ การตัดสินใจเด็ดขาด ประสบการณ์ บารมี และการบริหารคนที่อาจมีพลังเหนือกว่าตน
ห้ามเขียนผู้นำให้ดูไร้ความสามารถเพียงเพื่อยกความเก่งของผู้ใต้บังคับบัญชา หรือทำให้เป็นนักสู้ไร้เทียมทานทุกคน
ความเด็ดขาดอาจเป็นการถอนกำลัง ยอมเสียผลประโยชน์ หรือรับผลทางการเมือง ไม่ใช่การฆ่าทุกครั้ง

## แนวทางรายผู้นำ (ทั้งหมดเป็น DRAFT)
- อีธาน ครอส / เซ็นทรัล: ไม่มีพลัง; อดีตปฏิบัติการและข่าวกรอง ฝีมืออาวุธและการสั่งการสูง; ตัดสินใจคุ้มครองกำลังพลแม้เสียผลทางการเมือง
- โนอาห์ เกรย์ / นักสืบเกรย์: พลังสืบสวน ไม่ใช่พลังต่อสู้ชั้นยอด; ชำนาญภาคสนาม ต่อสู้และการอ่านสถานการณ์; พร้อมถอนตัวเมื่อเสียเปรียบ
- ลูเชียน เรเวน / มาเฟียเรเวน: ผู้มีพลังเงาระดับสูงแต่ไม่ใช่สุดยอดที่สุด; เติบโตในโลกใต้ดิน ผ่านการสู้จริง เก่งอาวุธ บริหารผลประโยชน์และจัดการคน
- เอเดรียน เวล / เอเพ็กซ์: พลังยังไม่เปิดเผย; เก่งบริหารความเสี่ยง การลงทุนและระบบความปลอดภัย ตัดสินใจสละสินทรัพย์เพื่อเป้าหมายใหญ่
- เอวา มอร์แกน / เฮเวน: ไม่มีพลัง; ผ่านงานช่วยชีวิตและเจรจาวิกฤต ยืนหยัดปกป้องคนในความดูแล; ไม่จำเป็นต้องเป็นยอดนักสู้
- มิเรอร์ / เครือข่ายมิเรอร์: ตัวตนและพลังยังไม่ทราบ; อำนาจจากการควบคุมข้อมูล เครือข่ายและอำนาจต่อรอง

## ใช้ประกอบการเขียน
แสดงบารมีผ่านการตัดสินใจภายใต้แรงกดดันและปฏิกิริยาของผู้ใต้บังคับบัญชา มากกว่าคำบรรยายว่า 'น่าเกรงขาม'; ให้ผู้นำมีข้อผิดพลาดและต้นทุนจากการตัดสินใจจริง
