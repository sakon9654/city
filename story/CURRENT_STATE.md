# สถานะเรื่องล่าสุด
บทที่อนุมัติล่าสุด: **ยังไม่มี**
เวลาปัจจุบันในเรื่อง: ยังไม่กำหนด
POV และสถานที่ปัจจุบัน: ยังไม่กำหนด
ตัวละครที่อยู่ในฉาก: ยังไม่กำหนด
การบาดเจ็บ/ทรัพยากร/ความลับที่กำลังค้าง: ยังไม่มี
เส้นเรื่องที่ยังไม่คลี่คลาย: ยังไม่กำหนด
**ก่อนเขียนบทถัดไปต้องแก้หน้านี้จากบทที่ได้รับการยืนยันแล้ว**
