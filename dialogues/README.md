# คลังบทสนทนาของตัวละคร
**แยกชัดเจน:** `dialogues/samples/` เป็นตัวอย่างการพูดเพื่อรักษาบุคลิก **ไม่ใช่เหตุการณ์ในเรื่อง**; `dialogues/canon/` เป็นบทสนทนาที่เกิดขึ้นในบทที่รับรองแล้ว พร้อม CH-ID และฉากอ้างอิง
เก็บหนึ่งไฟล์ต่อหนึ่งสถานการณ์และกลุ่มตัวละคร ตั้งชื่อ `DIA-0001_หัวข้อ.md`
ค้นหาด้วย CHAR-ID, REL-ID, บริบท, อารมณ์, ความลับ, สรรพนาม และช่วงเวลา
ตัวอย่างควรมีทั้งคุยปกติ คุยกับคนสนิท เจรจา ปะทะ และขณะเครียด โดยไม่ทำให้ทุกคนพูดสำนวนเดียวกัน
เมื่อมีบทที่อนุมัติ ให้คัดเฉพาะบทสนทนาที่เกิดขึ้นจริงไปเก็บใน `canon/` หรืออ้าง CH-ID แบบไม่ซ้ำข้อมูลทั้งบท
