# DIA-XXXX — ชื่อฉาก
สถานะ: SAMPLE (ไม่เกิดขึ้นจริง) / CANON (เกิดขึ้นจริง)
ตัวละคร: CHAR-... และ CHAR-...
ความสัมพันธ์: REL-...
บริบท: CTX-...
ช่วงเวลา: ก่อน/หลัง CH-ID (ถ้า CANON)
สถานที่: LOC-ID
เป้าหมายแต่ละคน / สิ่งที่แต่ละคนรู้ / สิ่งที่ไม่อาจพูด
ระดับอารมณ์และระยะห่างความสัมพันธ์:
## ตัวอย่างบทสนทนา
**[ชื่อ/CHAR-ID]:** “...”
**[ชื่อ/CHAR-ID]:** “...”
## ข้อสังเกตเสียงพูด
รูปแบบสรรพนาม การเลือกคำ จังหวะ เงียบ/ประชด วิธีหลบเลี่ยง
## ผลต่อความต่อเนื่อง (เฉพาะ CANON)
ข้อมูลใหม่ / คำสัญญา / ความสัมพันธ์เปลี่ยน / แหล่ง CH-ID
