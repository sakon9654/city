# คลังบริบทที่เปลี่ยนไปตามฉาก
CTX = สิ่งที่เกิดขึ้นในสถานการณ์หนึ่ง: เวลา/สถานที่/ฝ่ายที่เกี่ยวข้อง/ผู้รู้ข้อมูล/เป้าหมาย/เดิมพัน/เงื่อนไข/อารมณ์/กฎหมาย/เหตุการณ์ก่อนหน้า
บริบทต่างจากประวัติตัวละคร (ถาวรกว่า) และบทสนทนา (คำพูดที่แสดงออกจริง)
ใช้ `CTX-XXXX` ผูกกับ CH-ID และ DIA-ID เพื่อไม่ให้ใครรู้เรื่องก่อนเวลาหรือพูดเกินข้อมูลที่มี
บริบทระหว่างการวางแผน = DRAFT; บริบทที่เกิดแล้ว = CANON พร้อมหลักฐานฉาก
