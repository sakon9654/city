# องค์กรหลัก (ชื่อชุดล่าสุด = CONFIRMED)
| ชื่อ | สถานะ/หน้าที่ | จุดแข็ง |
|---|---|---|
| หน่วยเซ็นทรัล (Central Special Division) | หน่วยลับรัฐบาล สืบสวน ปกปิดเหตุการณ์ และจับกุมตามอำนาจ | กฎหมาย ข้อมูล อาวุธ |
| สำนักงานนักสืบเกรย์ (Grey Detective Agency) | เอกชน รับคดีเหนือธรรมชาติ คุ้มกัน ตามหา | ทีมเล็ก ความชำนาญเฉพาะ |
| มาเฟียเรเวน (Raven Mafia) | องค์กรใต้ดิน คุมการค้าผิดกฎหมายและอิทธิพล | เงิน เครือข่าย กำลังรบ |
| บริษัทเอเพ็กซ์ กรุ๊ป (Apex Group) | กลุ่มทุนเทคโนโลยี/แพทย์/วิจัย | เงินและบุคลากร |
| มูลนิธิเฮเวน (Haven Foundation) | ช่วยเหลือผู้มีพลัง โดยเฉพาะผู้เปราะบาง | ความไว้วางใจ บ้านพักปลอดภัย |
| เครือข่ายมิเรอร์ (Mirror Network) | นายหน้าข้อมูล ข่าวกรอง | ความลับและสายข่าว |
**ความสัมพันธ์ที่ยืนยันตามบทสนทนา:** เซ็นทรัล–เกรย์ร่วมมือระแวงกัน; เซ็นทรัล–เรเวนเป็นศัตรูทางกฎหมายแต่เจรจาลับ; เกรย์–เรเวนขัดแย้งและร่วมมือเป็นบางคดี; เอเพ็กซ์–เซ็นทรัลเป็นพันธมิตรธุรกิจ/เทคโนโลยี; เฮเวน–เกรย์ช่วยเหลือกัน; มิเรอร์ค้าหรือคุกคามทุกฝ่ายตามผลประโยชน์
หลักการเรียกชื่อในบท: ใช้ชนิดองค์กรพร้อมชื่อเมื่อจำเป็น เช่น ‘คนของมาเฟียเรเวน’, ‘เจ้าหน้าที่หน่วยเซ็นทรัล’, ‘นักสืบสำนักงานเกรย์’
