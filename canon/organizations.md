# องค์กรหลัก (ชื่อชุดล่าสุด = CONFIRMED)
| ชื่อ | สถานะ/หน้าที่ | จุดแข็ง |
|---|---|---|
| หน่วยเซ็นทรัล (Central Special Division) | หน่วยลับรัฐบาล สืบสวน ปกปิดเหตุการณ์ และจับกุมตามอำนาจ | กฎหมาย ข้อมูล อาวุธ |
| สำนักงานนักสืบเกรย์ (Grey Detective Agency) | เอกชน รับคดีเหนือธรรมชาติ คุ้มกัน ตามหา | ทีมเล็ก ความชำนาญเฉพาะ |
| มาเฟียเรเวน (Raven Mafia) | องค์กรใต้ดิน คุมการค้าผิดกฎหมายและอิทธิพล | เงิน เครือข่าย กำลังรบ |
| บริษัทเอเพ็กซ์ กรุ๊ป (Apex Group) | กลุ่มทุนเทคโนโลยี/แพทย์/วิจัย | เงินและบุคลากร |
| มูลนิธิเฮเวน (Haven Foundation) | ช่วยเหลือผู้มีพลัง โดยเฉพาะผู้เปราะบาง | ความไว้วางใจ บ้านพักปลอดภัย |
| เครือข่ายมิเรอร์ (Mirror Network) | นายหน้าข้อมูล ข่าวกรอง | ความลับและสายข่าว |
**ความสัมพันธ์ที่ยืนยันตามบทสนทนา:** เซ็นทรัล–เกรย์ร่วมมือระแวงกัน; เซ็นทรัล–เรเวนเป็นศัตรูทางกฎหมายแต่เจรจาลับ; เกรย์–เรเวนขัดแย้งและร่วมมือเป็นบางคดี; เอเพ็กซ์–เซ็นทรัลเป็นพันธมิตรธุรกิจ/เทคโนโลยี; เฮเวน–เกรย์ช่วยเหลือกัน; มิเรอร์ค้าหรือคุกคามทุกฝ่ายตามผลประโยชน์
หลักการเรียกชื่อในบท: ใช้ชนิดองค์กรพร้อมชื่อเมื่อจำเป็น เช่น ‘คนของมาเฟียเรเวน’, ‘เจ้าหน้าที่หน่วยเซ็นทรัล’, ‘นักสืบสำนักงานเกรย์’

## โครงสร้างกำลังและสมดุล (CONFIRMED)
องค์กรใหญ่ไม่จำเป็นต้องมีผู้ใช้พลังเด่นจำนวนมาก; องค์กรเล็กอาจมีบุคคลระดับสูงหลายคนจนถูกเกรงกลัว; กำลังรบไม่จำเป็นต้องเท่ากัน; ความได้เปรียบสลับตามเงิน ข่าวกรอง ทรัพยากร บุคลากร พันธมิตรและสถานการณ์ของแต่ละอาร์ก
จำนวนบุคคลสำคัญเริ่มต้นที่เสนอ: เซ็นทรัล 3, เรเวน 3, เอเพ็กซ์ 2, เกรย์ 5, เฮเวน 4, มิเรอร์ 3; ตัวเลขนี้เป็นแนวทางการจัดตัวละคร ไม่ใช่ข้อจำกัดตายตัวหรือจำนวนสมาชิกองค์กร
ผู้นำอาจไม่มีพลังต่อสู้ระดับสูง แต่ต้องน่าเชื่อถือจากทักษะ ประสบการณ์ ฝีมือ ความเด็ดขาด และการควบคุมคนจำนวนมาก
ตัวละครจากนอกเมืองสร้างเพิ่มตามเหตุการณ์ ไม่จำเป็นต้องมีรายชื่อถาวร
รายชื่อ/พลังของตัวละครที่เคยเสนอทั้งหมด ยังเป็น DRAFT

## มาเฟียเรเวน — หลักปฏิบัติ CONFIRMED (ผู้เขียนยืนยัน 2026-10-15)
- เรเวนเป็น **องค์กรมาเฟียที่ใช้อำนาจ กำลังรบ การข่มขู่ และความรุนแรงเพื่อแก้ปัญหา** ไม่ใช่กลุ่มที่ยึดภาพลักษณ์หรือกลัวคนเห็นการลงมือ ไม่ได้มีจริยธรรมทั่วไปว่าต้องหลีกเลี่ยงการกระทบประชาชน เจ้าหน้าที่ หรือคนไม่เกี่ยวข้อง
- **ข้อจำกัดเชิงนโยบายที่ยืนยัน:** หลีกเลี่ยง/ไม่รับงานที่เกี่ยวข้องกับ **เด็กและหญิงตั้งครรภ์**; ไม่ได้แปลว่าเป็นองค์กรฝ่ายดี ไม่ครอบคลุมคนทุกกลุ่ม และไม่ใช่ข้อห้ามการใช้ความรุนแรงในสถานการณ์อื่น
- การหลีกเลี่ยงเด็กและหญิงตั้งครรภ์คือเส้นที่องค์กรเลือกวาง ไม่ใช่การปฏิเสธอาชญากรรมทุกชนิด; การลักพาตัวเด็กโดยแก๊งใต้อิทธิพลจึงเป็นการละเมิดเส้นนี้อย่างชัดเจน
- **ความแตกต่างระดับบุคคล:** สมาชิกบางคน เช่น ชิราฮะ คานาเมะ อาจไม่ชอบงานวุ่นวายหรือความเสี่ยงที่ไม่จำเป็นเพราะวิธีทำงาน/อุปนิสัย ไม่ใช่ข้อบังคับที่ทั้งเรเวนกลัวการเผชิญหน้าหรือกลัวการถูกพบเห็น
- เรเวนไม่ใช่ผู้ว่าจ้างลักพาตัวในเล่ม 1; ออกคำสั่งเก็บหัวหน้าแก๊งเพราะฝ่าฝืนนโยบายและละเมิดอำนาจ ไม่ใช่เพราะหวั่นว่าจะกระทบภาพลักษณ์หรืออยากปกป้องเซ็นทรัล
- สมาชิกอาจมีทัศนคติและระดับความโหดต่างกันตามตำแหน่ง แต่ต้องไม่กลับไปเขียนว่าเรเวนทั้งองค์กรยึดหลักไม่ทำให้คนนอกเดือดร้อน
